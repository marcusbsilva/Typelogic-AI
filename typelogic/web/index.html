    Engine status

    Technical engine metadata
    In CPU and GPU mode the trained Qwen3.5-2B specialist (LoRA adapter and decision head) scores every alternative of every question. In Hybrid mode, questions with up to 16 alternatives go to a 4B generalist served on this computer by Ollama, which reads the option letters directly, and larger catalogs stay with the specialist.
    Field extraction (Needle 3). Checking…
    Data lives in ~/.typelogic-ai. The library keeps up to 200 decisions; then they are all compressed into data/DD-MM-YYYY.rar (or .zip without WinRAR) in the project folder. Stop the application before copying the data directory for backup. Application networking policy does not control browser extensions or other processes.
    The model is not a calculator, authorization mechanism or source of verified facts. Checksums detect changes against a stored baseline; they are not digital signatures. MD5 is included for compatibility, not security.
    

    ABOUT TYPELOGIC AI
    Structured decisions on your computer.
    Structured Decisions. Controlled Automation.
    What is TypeLogic AI?
    TypeLogic AI is an open-source decision intelligence solution for classification, scoring, evaluation and routing. You provide a scenario, ask focused questions and declare alternatives. The engine estimates a distribution over those alternatives and returns typed results for people and software.
    Our goal
    Make decisions easier to understand, review and measure, with local control over your data. Customer support, IT operations, purchasing, logistics and simulated game behavior are practical examples. The application works without external APIs.
    One contract, three output types
    1. Case
    The case as text, with typed evidence. Inputs remain on your computer.
    2. Questions
    Ask Yes / no, Choice or Score questions and declare their allowed outcomes.
    3. Typed results
    Read labeled answers and distributions, find them again in the Library by title and tag, and export JSON for integration.
    How it works
    Each question asks for a Yes / no judgment, a Choice or an ordinal Score. Results show the full question and a labeled answer. Help icons explain the indicators and their actual calculations.
    Your data
    The engine loads automatically. The web interface and CLI share a local database. Every decision is saved with a title and tags. Record correction stores an observed label. Delete removes the record, corrections and audit entries. At 200 decisions the library is archived into the project data folder. Full JSON preserves technical context; Lite JSON contains only the title, tags, questions and answers.
    What the indicators mean
    Typed output and high concentration do not guarantee accuracy. Declare an insufficient-evidence alternative when appropriate. The application only answers: it does not issue payments, send game actions or execute website requests. Measure quality on labeled cases from your domain before integrating any automation.
